## Quick Start

```bash
# List all components
tuiframe list

# Search components by keyword
tuiframe list --search data

# Inspect a component
tuiframe info block

# TUI browser
tuiframe browse

# Scaffold a new project
tuiframe scaffold mini-app my-app
```
